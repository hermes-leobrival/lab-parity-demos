# lab-parity-demos

Démos publiques du banc de mesure lab-parity (reproduction paritaire de sites).

- Chaque page « view-* » permet de basculer entre l'original (capture du site live) et le rebuild (copie statique préservée : HTML/CSS/JS/assets réellement servis).
- Trackers/analytics retirés des démos ; formulaires neutralisés (aucune action externe).
- Contenus tiers (Relume, Calendly, Raycast) : droits réservés à leurs propriétaires ; usage recherche/démonstration, sans affiliation.

Outil : repo privé lab-parity (mesures et protocole dans JOURNAL.md / REPORT.md de l'outil).
